# حلبة (Halba)

لعبة معارك لياقة مصنّفة 1v1 بالكاميرا — ضغط وملاكمة. الكاميرا تتبّع
نقاط الجسم (MediaPipe Pose) وتحسب غير التكرارات الحقيقية الكاملة —
هادا هو مانع الغش. مباراة 60 ثانية، شريط شدّ الحبل، تقييم ELO +
مستويات وXP.

Ranked 1v1 fitness battles by camera: push-ups and boxing. The camera
tracks pose landmarks (MediaPipe Pose) and counts only real, full
reps — that is the anti-cheat. 60-second matches, tug-of-war bar,
ELO rating + levels and XP.

- Live: https://devbymajid.github.io/halba/ (GitHub Pages)
- Tech: pure HTML/CSS/JS + MediaPipe Pose (in-browser, on-device).
  Zero cost. Video is never recorded or uploaded.
- Team log: TEAM-LOG.md — both Muses read it before starting work.
